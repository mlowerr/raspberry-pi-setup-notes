# AGENTS

## Project overview
This repository is a lightweight collection of Markdown notes for setting up and maintaining a Raspberry Pi running Manjaro ARM. The documents are task-oriented, shell-command focused, and intended to be quick reference checklists rather than long-form guides.

## Repository layout
- `Change hostname.md`: Quick hostname change commands.
- `Initial install packages.md`: Base package upgrade/install commands for a new Manjaro install.
- `Pacman reference.md`: Pacman command reference and related documentation link.
- `VNC Server Setup.md`: Steps and references for configuring TigerVNC on Manjaro ARM.

## Content conventions
- Keep notes concise and command-first.
- Use fenced code blocks for commands.
- Prefer plain Markdown without additional tooling or build steps.

## Maintenance workflow
- After completing each work request, **review and update this `AGENTS.md`** to capture any new project context or conventions.
- **Review and update `README.md` on every run** to keep the repository overview current.
